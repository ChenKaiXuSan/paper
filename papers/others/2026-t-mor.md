## 一句话总结

T-MOR 针对 vision-language models 擅长外观语义却缺乏显式人体运动建模、传统 skeleton models 又难以跨任务迁移的问题，在预训练阶段用 video 与 text 作为语义监督，通过 cluster-guided multimodal contrastive learning 将 skeleton motion 对齐到视觉与语言空间，并在下游只使用轻量 skeleton 输入完成分类、时序检测和零样本迁移。

## 研究问题与动机

人体动作不是静态外观类别，而是由具有时间结构和物理意义的身体运动定义。RGB/video foundation models 可以学习大规模视觉语义，但容易依赖场景、物体和人物外观；skeleton 则直接描述关节运动，对背景变化更稳健，但许多 skeleton-based methods 仍然在封闭 action label set 上训练，换数据集或新任务时需要重新训练。

T-MOR 希望兼顾两者：以 skeleton 作为最终 motion representation，同时借助 video 和 language 在预训练期间提供大规模语义信息。最终部署时不需要 RGB 或文本，只保留 skeleton encoder，使预训练阶段的多模态知识可以转移到更轻量的动作识别系统。

## 核心方法

### 1. Skeleton Motion Encoder

Skeleton sequence 被表示为 `T × J × C` 的时空张量，其中 `C=2` 或 `3`，因此同一框架可以处理 2D 与 3D skeleton。

作者使用 **UNIK** 作为 motion encoder。UNIK 结合 Transformer 与 TCN，同时学习 spatial joint relations 与 temporal evolution，最后通过时空 pooling 得到 motion embedding。下游分类任务在 pooled feature 上增加 classifier；frame-wise action detection 则保留时间维度进行逐帧预测。

### 2. Video 与 Text 语义锚点

T-MOR 使用冻结的 **ViCLIP** 提取 video embedding 与 text embedding。Video/text encoders 在预训练期间保持 frozen，主要训练 skeleton motion encoder 与各模态 projection heads。

因此设计目标不是让 skeleton 模型复制一个大型 VLM，而是把 VLM 的 visual-language semantic space 当作训练期的 teacher/anchor，使 skeleton embedding 获得更丰富的动作语义。

### 3. 两阶段 Multi-modal Contrastive Learning

预训练分成两个互补阶段：

**Self-supervised Motion–Video Pre-training**

- 对 skeleton 做 random temporal cropping 与 random rotation 得到正样本；
- 使用 motion–motion contrastive loss 学习动作不变性；
- 同时将 skeleton motion 与对应 video feature 对齐；
- 这一阶段不依赖 action label。

**Supervised Motion–Text Alignment**

- 将 skeleton embedding 与对应 action text embedding 对齐；
- 引入 language semantics，使 representation 能支持 zero-shot transfer。

最终 supervised objective 联合 `motion-motion + motion-video + motion-text` 三类 contrastive signals。

### 4. Cluster-Guided Contrastive Mechanism

普通 contrastive learning 容易把语义相似但来自不同 sample 的动作错误当作 negatives。T-MOR 每个 epoch 后对 motion embeddings 使用 **DBSCAN** 聚类：同 cluster samples 被视为更可能的 positives，其他 clusters 作为 negatives。

该机制用于 motion-motion、motion-video 和 motion-text alignment，目的是降低 false negatives，并让 motion embedding manifold 在不同模态之间保持更一致的语义结构。

### 5. PoseCap-1M

作者构建了 **PoseCap-1M**，包含超过 **100 万个同步 video–skeleton–text triplets**，用于大规模 multi-modal pretraining。

论文强调，现有 skeleton datasets 往往规模有限或来自受控实验室，而 PoseCap-1M 的目标是提供更加多样化的人体动作、视觉场景和语言描述。当前阅读时尚未核验到独立官方数据下载页，因此只记录论文明确给出的规模，不推断其公开可下载状态。

## 数据集与评价指标

### 预训练

- **PoseCap-1M：** >1M synchronized video–skeleton–text triplets。

### Action Classification

- **Toyota Smarthome：** real-world indoor action classification；报告 CS 与 CV2 accuracy。
- **UAV-Human：** 多视角/无人机人体动作；报告 CS1 与 CS2 accuracy。
- **Penn Action：** 体育动作视频；报告 Top-1 accuracy。

### Temporal Action Detection

- **Toyota Smarthome Untrimmed (TSU)：** 报告 CS / CV frame-wise performance。
- **Charades：** 报告 mAP。
- **PKU-MMD：** 用于 3D skeleton action detection，报告 event-level mAP@IoU 0.1/0.3/0.5。

### Transfer protocols

论文覆盖：

1. linear probing；
2. full fine-tuning；
3. zero-shot action recognition；
4. 3D action detection transfer；
5. multimodal objective ablation。

下游 evaluation 阶段主要只使用 skeleton 和 motion encoder，不再依赖 training-time 的 video/text inputs。

## 主要结果

### 1. 2D Skeleton Action Classification

Linear probing 时，完整 `V+M+T` 预训练得到：

| Dataset / Protocol | T-MOR V+M+T | 无预训练 UNIK |
| --- | ---: | ---: |
| Smarthome CS | **52.6** | 24.6 |
| Smarthome CV2 | **53.4** | 20.7 |
| UAV-Human CS1 | **33.5** | 3.8 |
| UAV-Human CS2 | **60.1** | 4.1 |
| Penn Action Top-1 | **97.8** | 29.8 |

Fine-tuning 时，完整 T-MOR 达到 Smarthome **66.2/66.7**、UAV-Human **44.4/70.8**、Penn Action **98.2**。

论文特别指出，与随机初始化 UNIK 相比，linear probing 在 Smarthome CV2 提升 **32.7 percentage points**，Penn Action 提升 **68.0 points**，说明预训练 representation 在小型或跨域下游任务中包含较强可迁移信息。

### 2. Temporal Action Detection

Linear probing：

| 方法 | TSU CS | TSU CV | Charades mAP |
| --- | ---: | ---: | ---: |
| UNIK，无预训练 | 8.1 | 6.9 | 6.1 |
| T-MOR V+M | 19.8 | 12.6 | 11.3 |
| **T-MOR V+M+T** | **23.2** | **19.4** | **16.6** |

Full fine-tuning 后，T-MOR V+M+T 达到 **38.3 TSU CS、23.6 TSU CV、26.0 Charades mAP**。

这说明 multi-modal pretraining 的收益不局限于 clip-level classification，也能迁移到需要时间定位的 frame-wise action understanding。

### 3. 3D Skeleton Action Detection

在 PKU-MMD cross-subject 上，T-MOR 只使用 skeleton input，event-level mAP 为：

- IoU 0.1：**94.3%**；
- IoU 0.3：**93.2%**；
- IoU 0.5：**90.7%**。

作为对比，Window Proposal skeleton baseline 在 IoU 0.1/0.5 为 92.2/90.4。

### 4. Multimodal Objective 消融

Linear probing：

| Pretraining objective | Smarthome CS | TSU CS |
| --- | ---: | ---: |
| None | 24.6 | 8.1 |
| Motion–Motion | 42.5 | 12.8 |
| Motion–Video | 46.3 | 16.3 |
| Motion–Text | 49.0 | 18.6 |
| MM + MV + MT, PoseCap-1M | **52.6** | **23.2** |

Video 与 text 都能在单独对齐时改善 skeleton representation，而三模态联合结果最好，支持作者关于视觉语义、语言语义与运动结构互补的判断。

## 优点

- 把 RGB/video 与 text 当作**训练期 privileged information**，但推理只需要 skeleton，兼顾多模态表征能力和部署成本。
- PoseCap-1M 将 motion/video/text 统一到百万级 triplet 规模，为 skeleton foundation-style pretraining 提供了较大规模的数据基础。
- 不只评估 clip classification，还覆盖 frame-wise detection、3D skeleton detection 和 zero-shot transfer。
- Cluster-guided contrastive learning明确针对 false negatives 问题，而不是简单增加更多 pairwise losses。
- Penn Action、UAV-Human、Smarthome 等跨场景结果说明预训练表征具有一定跨数据集迁移能力。
- 论文结论明确把 **optical flow** 作为未来可加入的预训练模态，这一点与 RGB/光流/关键点融合方向高度相关。

## 局限

- **适用边界：** 所有下游任务都是通用 human action recognition/detection，没有患者步态、脊柱疾病或其他 clinical endpoint，因此医疗领域的有效性仍需独立验证。
- **推断：** T-MOR 对 skeleton quality 有依赖；如果关键点估计在遮挡、辅助器具、异常姿势或患者特殊体型上存在系统偏差，motion representation 也可能继承这些偏差。
- ViCLIP video/text encoders 被作为冻结的语义 teacher，因此预训练获得的语义结构可能受到 foundation model 本身的 action vocabulary 与视觉偏差影响。
- PoseCap-1M 的规模很大，但截至阅读日期未核验到独立官方公开下载页，也未核验到官方代码仓库，因此当前可复现性和数据访问条件仍不够明确。
- 在临床任务中，动作类别通常不是“playing tennis”这样清晰的语义标签，而是连续 severity 或细微运动异常；语言对齐是否仍然带来同等收益不能由现有实验直接推出。

## 个人评价

T-MOR 最值得借鉴的地方是**训练时多模态、推理时单模态**的设计。临床数据经常存在一个现实矛盾：研究阶段可以获得 RGB、optical flow、2D/3D pose、医生评分甚至文本描述，但实际部署希望只依赖最稳定、成本最低的一类输入。T-MOR 提供了一种通过 contrastive pretraining 把额外模态知识蒸馏进 motion encoder 的思路。

其百万级 pretraining 和跨多个 downstream benchmarks 的实验比单数据集 supervised skeleton classifier 更有说服力。不过，对于医疗动作，真正有价值的信息往往是连续、细粒度和低幅度的，因此从通用 action semantics 迁移到 disease-specific representation 仍然需要重新设计文本语义和评价协议。

阅读优先级：**高**。

## 与我的研究关联

T-MOR 对 RGB、光流、关键点多模态融合和临床动作识别都有较强方法启发。可以考虑：

- 训练期使用 `RGB + optical flow + keypoints` 做 contrastive alignment，测试期只保留 keypoint 或 RGB branch；
- 将 gait phase、临床 severity、症状描述或身体部位描述转成 text supervision，与 motion embedding 对齐；
- 用跨 subject / cross-site / leave-one-dataset-out protocol 检查预训练是否真正改善临床泛化，而不是只提高同域 accuracy；
- 把 PhaseMix/周期 motion feature 当作额外 motion view，与原 skeleton embedding 做 MM-style contrastive learning；
- 在较大的健康动作数据上预训练，然后迁移到小样本 ASD/PD gait classification，比较 scratch、self-supervised skeleton 和 multimodal-pretrained encoder。

以上为基于 T-MOR 设计的**推断性迁移建议**，并非论文已经在医疗数据上证明的效果。
