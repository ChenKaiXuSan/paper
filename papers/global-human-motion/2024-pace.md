## 一句话总结

PACE 将 foreground human motion prior 与 background SLAM scene features 放入统一的 bundle-adjustment-style 优化，在单目移动视频中不仅恢复 world-space human motion，而且显式联合优化完整 camera rotation / translation / scale，并在 HCM 上证明人体与场景的联合约束能降低 camera trajectory error。

## 研究问题与动机

Moving-camera video 中 human motion 与 camera motion 在图像上相互耦合。仅靠人体 motion prior 无法唯一确定 global trajectory；仅靠 SLAM 又会受到动态人体和 monocular scale ambiguity 的影响。此前方法常把 SLAM 作为固定初始化，或者只利用人体先验估计 camera scale，因而 camera trajectory 的局部错误会直接传递到 world-space human motion。

PACE 的核心问题是：能否让人体 motion prior 与背景 scene feature 互相约束，在同一个优化中同时纠正 human trajectory 与完整 camera trajectory，而不是只做串联或 scale calibration。

## 核心方法

### 初始化

方法先用多目标 tracking / re-identification 获得人物轨迹，以 HybrIK 初始化 camera-frame SMPL body pose，并用 DROID-SLAM 得到 up-to-scale camera trajectory 与 point cloud。由于初始 camera translation 没有 metric scale，第一阶段主要用 camera rotation 将人体 root orientation 转入统一 world frame，同时由人体 local motion 预测初始 global root translation。

### Parallel human motion prior

PACE 基于 NeMF 构建 non-autoregressive motion VAE prior。与逐帧 autoregressive prior 不同，128-frame overlapping windows 可以并行优化，使用 16-frame overlap 和 consistency loss 保持片段连续性。motion prior 同时约束 global orientation、local body pose、root translation 与 contact，使人体运动为 camera refinement 提供可微的动态先验。

### Joint human-camera optimization

统一目标由三部分组成：`E_body` 包括 2D reprojection、shape、pose、smoothness、VAE 与 window consistency；`E_scene` 包括 contact 与 ground-height 约束；`E_camera` 使用去除人体 bounding boxes 后的 SLAM point-cloud reprojection 与 camera smoothness。

优化采用四阶段策略：先校准 camera scale / first-frame transform 与 body shape，再逐步加入 global human orientation、local pose，最后在 Stage 4 **联合优化每帧完整 camera `R_t/T_t` 与人体 latent motion**。因此 PACE 是明确的 human-scene-camera full-trajectory joint optimization 先例，而不是只做 human-assisted scale recovery。

## 数据集与评价指标

- **HCM（Human and Camera Motion）：**作者构建的 synthetic benchmark。使用 RenderPeople characters、AMASS motions、Unreal Engine scenes 与 NVIDIA Omniverse 渲染，人数为 1–8 人，共 **25 条 evaluation video sequences**；同时提供 global human 与 camera ground truth。
- **RICH：**包含 7 台 static cameras 与 1 台 moving camera；论文利用其 world-space human ground truth 评估 global human motion。moving-camera ground-truth pose 不可用，因此该数据上不报告 camera trajectory error。
- **EgoBody：**附录在 validation split 上评估；使用 DROID-SLAM 与数据集提供的 ground-truth camera intrinsics。
- **输入：**moving-camera monocular RGB video。
- **输出：**每帧 camera rotation / translation，以及所有可见人的 world-space SMPL motion。
- **人体指标：**W-MPJPE、WA-MPJPE、W-RJE、PA-MPJPE、ACCEL。
- **相机指标：**ATE、ATE-S（不做 scale alignment）与 CAM ACCEL。

## 主要结果

- **HCM：**PACE 的 W-MPJPE / WA-MPJPE 为 **861.2 / 478.3 mm**，SLAHMR 为 888.9 / 483.5 mm，HybrIK+SLAM 为 1137.3 / 780.3 mm。
- **Camera refinement：**HCM 上 HybrIK+SLAM 初始化的 ATE / ATE-S 为 **155.8 / 1670.7**，PACE 降至 **137.5 / 459.7**；论文总结为 scale-aligned ATE 改善约 12%，无 scale alignment 的 ATE-S 改善约 74%。
- **RICH：**PACE W-MPJPE / WA-MPJPE 为 **380.0 / 197.2 mm**，SLAHMR 为 571.6 / 323.7 mm，GLAMR 为 653.7 / 365.1 mm。
- **EgoBody：**PACE W-MPJPE / WA-MPJPE / PA-MPJPE / ACCEL 为 **147.9 / 101.0 / 66.5 / 6.7**，SLAHMR 为 141.1 / 101.2 / 79.13 / 25.78；说明其 global accuracy 与 SLAHMR 接近，但 local pose、smoothness 和效率更好。
- **效率：**1000-frame sequence 平均少于 **8 min**；论文报告 SLAHMR 对同等长度按其线性增长约需 400 min，PACE 可快约 50×。
- **消融：**去掉 point-cloud reprojection 后，HCM 的 ATE 从 137.5 恶化到 166.4，说明背景 scene geometry 对稳定 camera optimization 是必要的；直接从所有变量同时优化也无法稳定收敛。

## 优点

- 不只把 SLAM 当固定输入，而是显式让 human motion prior、2D reprojection 与 background point cloud 共同修正完整 camera trajectory。
- 同时报告 human world-space error 与 camera ATE / ATE-S，可直接验证 human-camera coupling 是否真的改善 camera，而不是仅让人体吸收 camera error。
- NeMF parallel prior 显著降低 batch optimization 的时间成本，为长序列 joint refinement 提供了早期可行基线。
- HCM 提供同时具备 human 与 camera GT 的动态视频 benchmark，允许拆分 camera / human 两侧误差来源。

## 局限

- 作者明确指出：当 SLAM **catastrophically fails** 时，PACE 也可能无法有效恢复，因为 joint optimization 仍依赖合理的几何初始化。
- 方法假设 planar ground；该假设来自 AMASS 缺少真实 scene annotation 的限制。
- 不是实时方法，需要 batch processing 并利用过去与未来帧。
- 优化中的 perspective projection 使用已知 camera intrinsics；EgoBody 实验也使用 ground-truth intrinsics，因此并未解决 unknown / varying intrinsics。
- **推断：**HCM 是 synthetic，RICH 又没有 moving-camera GT，所以对高速户外、低纹理、强旋转和长期 scale drift 的 camera-side证据仍有限。

## 个人评价

PACE 是 camera-human mutual refinement 路线中必须补齐的经典工作，因为它已经在 3DV 2024 明确实现 `human prior + background geometry → full camera R/t refinement`，并用 ATE 定量证明 camera 真的变好。这意味着后续工作不能把“首次让人体反向纠正 camera trajectory”作为宽泛 novelty。

真正有空间的方向应更具体：现代 foundation HMR / dense geometry、在线 learned refinement、uncertainty-aware residual、unknown intrinsics、multi-moving-camera，以及 fisheye / ERP / dual-360 几何。

## 与我的研究关联

**推断：**对于 dual-360 moving-camera skiing，最清晰的 baseline 链应包含 `camera-only SLAM → fixed-camera HMR → human-assisted scale → PACE-style full R/t joint optimization → spherical / multi-camera uncertainty-aware refinement`。这样可以直接回答 proposed method 相比经典 optimization-based camera-human coupling 究竟新增了什么。

PACE 的 `E_body + E_scene + E_camera` 结构也很适合迁移：将 pinhole 2D reprojection 改为 ERP / fisheye spherical reprojection，将 static-background point cloud residual 换成 panorama geometry / VIO residual，再加入双 360 cross-view body consistency、bone length、ski-ground contact、velocity / acceleration 与 per-observation confidence。应同时报告 camera ATE/RPE/scale drift 与 human W-MPJPE/RTE/Jitter。

## 后续阅读

- SLAHMR：PACE 直接比较的 global human-camera optimization baseline，主要优化 camera scale 与 world human trajectory。
- BodySLAM++：visual-inertial factor graph 中的 tightly-coupled camera-human tracking。
- SynCHMR：人体 metric cue 校准 monocular depth / SLAM scale，再由 scene 反向约束人体。
- Human3R / SHOW / JOSH：从 shared recurrent state、feed-forward coupling 到更现代 joint reconstruction。
- **计划实验：**分别人为注入 focal、rotation、translation、scale drift，比较 PACE-style full trajectory optimization 与 proposed learned / spherical refinement 的纠错范围和失效模式。
