## 一句话总结

SHOW 把 human mesh recovery 与 feed-forward scene reconstruction 从“并行后对齐”推进到显式双向耦合：人体语义与 metric-scale prior 进入几何模型，场景几何再反向约束 SMPL-X 的尺度与全局位置，使二者在同一 metric space 中联合学习。

## 研究问题与动机

移动单目相机下同时恢复人体与环境时，尺度歧义、人体与场景错位以及遮挡会相互放大。已有 world-grounded HMR 可以恢复全局人体轨迹，但往往没有把人体放到真实 scene geometry 中；另一方面，Human3R、UniSH 等 feed-forward human-scene 方法虽然同时预测人和场景，human branch 与 geometry branch 的信息交换仍较有限，常依赖后处理、局部定位线索或额外 alignment network。

SHOW 的核心观点是：human 与 scene 本来处于同一物理空间，因此应在表示层就互相约束。人体模型提供可解释的语义结构与尺度先验，场景 point map 则提供空间位置、相机与深度上下文。模型目标不是分别得到“看起来合理”的人体和场景，而是让两者在尺度、位置和可见表面上保持一致。

## 核心方法

SHOW 由三部分构成：

1. **Human-Aware Geometry Encoding**：以 VGGT 为视觉几何 backbone，加入 human mask encoder，并通过 DensePose 辅助监督让 latent geometry features 显式学习人体表面语义，而不是把人物仅当普通前景。
2. **Geometry-Aware SMPL-X Decoding**：使用 PromptHMR 提供 human-centric features，同时把 adapted geometry features 送入 Transformer decoder；模型使用 SMPL token、scale token 和 register token，并加入由预测相机内参计算的 ray positional encoding，预测 SMPL-X pose、shape、global translation 与 scene scale。
3. **Joint Human-Scene Fine-tuning**：通过 scale supervision、跨帧 scale consistency 和 SMPL-guided point-map Chamfer alignment，把人体可见表面与 human-mask 区域的 scene point map 对齐，使 human branch 与 scene branch 在同一 metric 3D space 中共同更新。

此外，mask-as-prompt 让模型可选择目标人物，并在多人重叠、局部遮挡和复杂背景下减少无关区域干扰。

## 数据集与评价指标

论文在 **BEDLAM2.0** 上训练。作者过滤 HDRI depth 渲染不准确的序列后保留 **4,250 个有效序列**，训练视频降采样到 6 FPS，并使用 5 帧 clip。

评估包括：
- **3DPW、EMDB subset 1**：PA-MPJPE、MPJPE、PVE，评估 camera-space/local mesh accuracy；
- **EMDB subset 2、RICH**：将序列分成 100-frame segment，报告 W-MPJPE、WA-MPJPE、RTE，评估 world/global trajectory；
- **Human-scene alignment**：作者提出 HS-CF（Human-Scene Chamfer）与 HS-V（Human-Scene Variance），直接衡量 SMPL-X visible surface 与 human-region point map 是否匹配。

这一评价体系值得注意，因为它同时检查 local body、world trajectory 和 human-scene metric consistency，而不是只报告 pelvis-relative pose error。

## 主要结果

在 local HMR 上，SHOW 在 3DPW 达到 **41.0 mm PA-MPJPE / 67.7 mm MPJPE / 78.7 mm PVE**，在 EMDB-1 为 **45.8 / 75.7 / 88.8 mm**。它并非所有 local 指标的最佳方法，但在 joint human-scene feed-forward 方法中表现有竞争力。

在 global evaluation 上，SHOW 在 EMDB-2 达到 **109.1 mm WA-MPJPE、262.3 mm W-MPJPE、2.1% RTE**；在 RICH 为 **107.3 mm、172.7 mm、2.2%**。相较 Human3R（EMDB-2: 112.2/267.9/2.2）与 UniSH（118.5/270.1/5.8），SHOW 的 shared-space coupling 更稳定。优化式 JOSH 在部分 global 指标上仍明显更强，说明 feed-forward 速度与最终精度之间仍有差距。

消融中，去掉 joint modeling 后 3DPW HS-CF5 从 **9.44** 恶化到 **17.32**；去掉 mask prompt 为 **14.12**；去掉 ray encoder 会使 HS-V5 从 **0.028** 恶化到 **0.734**。最终 E2E joint tuning 将 HS-CF5 从 **9.44** 降至 **6.21**，说明 human-scene 双向表示与共同微调都具有实际贡献。

## 优点

- **双向 coupling 很明确。** Human prior 不只是最终输出或 post-hoc scale cue，而是直接改变 geometry representation；scene geometry 又反向进入 SMPL-X decoder。
- **把 metric scale 放进统一模型。** Scale token、ray encoder 与 point-map alignment 让 camera、scene、human 的尺度关系成为训练目标。
- **评价更贴近真实 world reconstruction。** 除 W-MPJPE/RTE 外，还提出 HS-CF/HS-V 检查人体和环境是否真的处于一致空间。
- **适合与 UniSH / Human3R / JOSH 对照。** 可以清晰比较“冻结后对齐”“feed-forward joint feature coupling”和“optimization-based joint refinement”三种范式。

## 局限

- 作者明确指出仍存在 **sim-to-real gap**；模型主要在大规模 synthetic BEDLAM2.0 上训练，面对真实分布外场景时性能下降。
- 对 **极端尺度变化**、人物在画面中非常小的情况仍不稳健。
- SHOW 是 feed-forward unified reconstruction，但论文没有证明其能在超长序列中持续迭代修正 camera trajectory drift。
- **推断：**对于滑雪等低纹理雪地、快速视角旋转和长距离 camera motion，human-scene feature coupling 可能改善局部尺度/定位，但若 camera trajectory 本身累积严重旋转或平移漂移，仍需要显式 temporal / SLAM / recurrent correction。

## 个人评价

SHOW 对当前 moving-camera 研究线很重要，因为它补上了 WHAC 和 JOSH 之间的一种中间形态：WHAC 主要做 `human → camera scale → human`，JOSH 更偏 optimization-based joint refinement，而 SHOW 在 **feature representation 与 loss 层面**直接让 human 与 scene 双向交互，并保持 feed-forward 推理。

最值得借鉴的是两点：第一，把人体 mask / DensePose / body-scale prior 当成 geometry backbone 的结构性提示，而不是 HMR 之后再使用；第二，把 scene point map、camera intrinsics 和 human body token 放到同一个 decoder 中。对于多 360° 系统，可以进一步把多个 perspective crop 的 human evidence 汇总为物理相机的 geometry prompt。
