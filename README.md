# Paper Reading Notes / 论文阅读笔记

## About / 关于

This repository collects my bilingual notes on research papers in computer vision, 3D human pose estimation, 360° vision, multiview learning, and medical AI.

本仓库用于整理我的双语论文阅读笔记，主要关注计算机视觉、三维人体姿态估计、360° 视觉、多视角学习和医疗人工智能。

The notes reflect my personal understanding at the time of reading. They are summaries and commentary, not substitutes for the original papers.

这些内容记录阅读当时的个人理解，属于总结与评论，不能替代论文原文。
